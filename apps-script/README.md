# 会議OS — Apps Script 導入手順（Phase 1）

`Code.gs` は、Google Sheets テンプレ（build_template.py v5 が生成する4タブ）を
**人手ゼロの閉ループ**にするための自動化。

## できること
- **① 新しい会議を始める**：テンプレ「▶ 会議」を複製し日付で命名。台帳の未結論の論点を新会議の「論点リスト」へ自動セット（持ち越し）。
- **② この会議を台帳へ取り込む**：開いている会議シートの「決定（スクライブ種別=決定）」と「③ToDo」を🗂台帳へ自動追記（同じ会議×同じ内容は重複スキップ）。
- **最終更新の自動打刻**：台帳の行を編集すると `最終更新日` 列が自動更新 → 「停滞(>14日)」が本当に自動で浮く。
- **棚卸し表示**：未完/期限超過/停滞/担当なし の件数をトースト表示。

## 導入（1回だけ）
1. 対象スプレッドシート（v5: `1Hdd2YDLXJWUDa2qxr40svh32ChPTTo_8HeFczsSnABk`）を開く
2. メニュー **拡張機能 → Apps Script**
3. 既定の `Code.gs` を消して、本 `Code.gs` の中身を貼り付け → 保存（💾）
4. スプレッドシートを**リロード** → 上部にメニュー **「会議OS」** が出る
5. 「会議OS → ① 新しい会議を始める」を初回実行 → **権限の承認**（自分のアカウントで許可）

## 使い方（毎回）
1. 「会議OS → ① 新しい会議を始める」で今日の会議シートを作る
2. 会議中：②進行のスクライブで `意見/論点/決定` を記録、③確認でToDoを書く
3. 「会議OS → ② この会議を台帳へ取り込む」で決定・ToDoを🗂台帳へ
4. 台帳で状態を更新（編集すると最終更新日が自動で入る）
5. 次回は冒頭で「棚卸し：要対応を表示」で前からの放置・盲点を確認

## 注意 / 既知の制約
- `Code.gs` 冒頭の `M`（会議シートの行・列）と `L`（台帳の列）は **v5レイアウト準拠**。
  テンプレ（`build_template.py`）の行構成を変えたら、ここも合わせて更新する。
- `onEdit` は simple trigger（自動・承認不要）。複雑な権限が必要な処理はメニュー実行時に承認。
- 会議シートの判定は「シート名の先頭が ▶」。複製した会議シートを開いた状態で②を実行すること。
- Phase 2（Webアプリ化）でこの自動化は移植・置換予定。SoT は `docs/PRD.md`。
