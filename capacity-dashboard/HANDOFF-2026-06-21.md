## 5. 運用の勘所（本セッションの教訓）
- **委譲マーカー**: views編集の前後で `touch`/`rm`。Workflowを背景起動した場合はその間マーカーを開けっ放しにしない（独立作業で衝突注意）。
- **E2E検証**: capdemo トークンを sessionStorage `taskstation_token` に注入（ブラウザ内 login fetch）。**触ったデータは必ず復元**＝prepは `savePrep(id,{})`／started_at・due はゼロ値 `0001-01-01T00:00:00Z`／plan は deletePlan／ポモは `localStorage.removeItem('ts.pomo')`／手法ON状態は `ts.execsupport.enabled`/`.order` を removeItem。
- **store cache-bust の罠**: 検証で `import('/app/lib/store.js?t=...')` するとアプリ本体と別インスタンスになり `load(true)` が反映されない。アプリと同じ挙動を見たいときは**クエリ無し**でimport。
- **exec.py 改修**: repo `ops/taskstation-exec.py` → `cp ~/.local/bin/` → `systemctl --user restart taskstation-exec` → is-active＋repo↔deploy diff 確認。
- **`rm *.png` 厳禁**: 追跡中のmockup pngを巻き込む（本セッションで誤削除→git checkoutで復旧）。スクショは個別ファイル名で削除。
- **node テスト**: `lib/*.test.mjs` は全127件グリーン（capacity32/notify6/execmetrics5 他）。exec-support.js は location 参照で node import 不可＝純関数は lib に出してテスト。
